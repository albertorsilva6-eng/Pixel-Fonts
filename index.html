LEVEL 02 — APRENDIZADO

Como utilizar fontes externas?

O Google Fonts permite adicionar diferentes tipografias aos projetos HTML e CSS. Basta importar a fonte no HTML e utilizar a propriedade font-family para aplicá-la aos elementos da página.

▣ EXEMPLO DE CÓDIGO CSS 
.titulo {
    font-family: 'Press Start 2P', cursive;
}

.paragrafo {
    font-family: 'DM Sans', sans-serif;
}

.destaque {
    font-family: 'Montserrat', sans-serif;
}
